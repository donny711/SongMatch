# SoundMatch

Music discovery app for iOS - swipe through tracks, find your taste.

SoundMatch uses Last.fm and Deezer data to build a personalized taste profile. Swipe on 30-second previews, match with other listeners, and discover what you actually love.

## Tech Stack

- React Native (Expo SDK 55)
- TypeScript
- Firebase (Firestore, Auth, Storage)
- Node.js (Cloud Functions)
- Last.fm API + Deezer API
